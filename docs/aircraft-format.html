Aircraft JSON Format

Every aircraft in Sims Checklist is one JSON file. This page documents each field, its type and units, and how the fuel calculator uses them — with the Cessna 172 Skyhawk as a complete working example.

file aircraft.json encoding UTF-8 icon JPEG
Prefer filling in a form? Open the Checklist Editor to build the JSON visually and download a valid file.
cessna172.json 
{
  "id": 0,
  "name": "Cessna 172 Skyhawk",
  "performance": {
    "fuelCapacity": 56,        // gallons
    "averageCruiseSpeed": 100, // knots
    "averageFuelFlow": 8       // gallons / hour
  },
  "checklists": [
    {
      "id": 0,
      "caption": "ENGINE START",
      "items": [
        { "caption": "Brakes", "action": "TEST & SET" }
      ]
    }
  ],
  "photo": "cessna172"
}
01 · schema

Field reference

The top-level object has five fields. Required fields must be present; optional fields fall back to the defaults shown.

  • top level
  • performance

Aircraft record

root object

FieldTypeRequiredDescription
idintegeryesUnique aircraft id. On import the app replaces it with the next free id, so any value works.
namestringyesDisplay name, e.g. Cessna 172 Skyhawk. Must be non-empty and unique across all aircraft (case-insensitive).
performanceobjectyesPerformance numbers used by the fuel calculator. See below.

Performance

performance

These values feed the block-fuel calculation. The first three are required and must be positive; the rest are optional with sensible defaults. Units matter — see the fuel calculator section.

reservesMinutesintegerminutes45Final reserve time, converted to fuel at cruise flow (0–89).

Checklist

checklists[]

FieldTypeRequiredDescription
idintegeryesUnique within this aircraft. Use sequential ids starting at 0.
captionstringyesChecklist title, stored in uppercase, e.g. ENGINE START. Non-empty.
itemsarrayyesOrdered checklist items. See below.
categorystringnoOne of NORMAL, NON_NORMAL, PROCEDURE. Defaults to NORMAL. Colors the card: procedure = blue, non-normal = red.
isCompletedbooleannoCompletion flag, managed by the app. Defaults to false; you can omit it.

Checklist item

checklists[].items[]

FieldTypeRequiredDescription
captionstringyesThe item to check, e.g. Brakes. Non-empty.
actionstringyes*The expected state, uppercase, e.g. TEST & SET. Non-empty for normal items.
detailsstringnoExtra notes shown under the item. Use \n for line breaks. Defaults to empty.
checkedbooleannoCheck state, managed by the app. Defaults to false; you can omit it.
Separator lines. To draw a visual divider inside a checklist, add an item whose caption is exactly LINE. Such an item may have an empty action and is not counted toward completion.
02 · units & math

How the fuel calculator uses these fields

Distances are in statute miles as shown in the app, speed in knots, fuel in US gallons. The calculator turns distance into time using cruise speed minus headwind, then multiplies by fuel flow.

trip fuel = tripDistance / (cruiseSpeed − headwind) × fuelFlow
alternate fuel = alterDistance / (cruiseSpeed − headwind) × fuelFlow
contingency = fuel for (tripDistance × contingency / 100)
reserve = reservesMinutes / 60 × fuelFlow
block fuel = trip + alternate + contingency + taxiFuel + reserve

Worked example with the Cessna 172 numbers above — a 100 sm trip, no alternate, no headwind, and the default taxi / contingency / reserve values:

Trip fuel · 100 sm ÷ 100 kt × 8 gph8 gal
Alternate fuel · 0 sm0 gal
Contingency · 5% of trip0 gal
Taxi fuel1 gal
Reserve · 45 min at 8 gph6 gal
Block fuel15 gal
Capacity check. If block fuel exceeds fuelCapacity (56 gal here), the result field turns red and reads "Fuel exceed!". Set fuelCapacity to the aircraft's real usable fuel so this warning is meaningful.
03 · icon

The icon image

Each aircraft needs a separate JPEG icon, selected alongside the JSON file. The app validates it before saving.

  • Format: JPEG (PNG and other formats are rejected)
  • File size: 50 KB or less
  • Dimensions: 200 px or less on each side
  • Proportions: width and height within 10% of each other
A 150×150 px JPEG is the sweet spot — it matches the bundled aircraft icons. A slightly non-square image such as 152×150 is fine; 150×180 is not.
04 · import

Adding your aircraft

Open the tools menu on the main screen and choose Add custom aircraft. The app checks everything before it writes a single file.

  1. Select the JSON file. It is parsed strictly and checked against the rules below. Errors appear next to the file control.
  2. Select the JPEG icon. It is checked for format, size, dimensions and proportions.
  3. Confirm image rights. Tick the box declaring you own the image or obtained it from a free source.
  4. Save. The app assigns the next free id, rewrites the photo label, and stores both files in its data directory. Your aircraft appears in the list immediately.

Validation rules

  • Valid JSON matching the schema exactly — unknown fields are rejected
  • Required fields present: name, performance, checklists
  • Performance values positive; taxi / contingency / reserve non-negative
  • Checklist ids unique within the aircraft
  • Item captions and actions non-empty (except LINE separators)
  • Category is NORMAL, NON_NORMAL or PROCEDURE
  • Aircraft name not already used by another aircraft
  • Icon passes all four image checks
Removing an aircraft. Custom aircraft show a trash-can icon on their card. Confirming removes both files. Bundled aircraft cannot be removed.
