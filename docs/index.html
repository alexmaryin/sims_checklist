FAQ

Common Questions

Everything you need to know before your first flight.

Does it work without internet?
Yes. All checklists and the airport database work offline. METAR/TAF weather data requires an internet connection to fetch from CheckWX API.
Which aircraft are supported?
Currently three aircraft: Cessna 172 Skyhawk (the classic trainer), Cirrus SR-22 (modern GA with glass cockpit), and Cessna Citation X (X-Plane 12 default, business jet). More aircraft may be added in future updates.
Will there be an iOS version?
Currently available on Android and Desktop (Windows, Linux, macOS). Follow the GitHub repository for updates on platform expansion.
Where does the airport data come from?
The airport database is sourced from OurAirports, a community-driven project with 85,000+ airports worldwide. Data is fetched from CSV files and stored in a local SQLite database for incredibly fast performance.
Why are runway headings in true courses, not magnetic?
METAR wind reports reference true north, not magnetic. To accurately visualize headwind and crosswind components relative to your aircraft's track, we use true course runway headings. This ensures correct wind component calculation for your flight planning.
