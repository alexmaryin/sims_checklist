⚙️ Технические требования для Gutenberg + Inspiro Lite:

* Формат вывода: чистый, семантический HTML + CSS, готовый для вставки в блок «Пользовательский HTML».
* Не использовать внешние JS-библиотеки. Анимации — только CSS (hover, fade-in).
* Вынести стили в CSS-переменные в :root, чтобы легко адаптировать под цветовую схему темы:
:root {
--primary: #2563eb; /\* акцентный цвет кнопок */
--bg-dark: #0f172a; /* для тёмных секций \*/
--text-main: #1e293b;
--text-light: #f8fafc;
}
* Использовать классы-обёртки с префиксом `.sims-` (например, `.sims-hero`, `.sims-features`), чтобы не конфликтовать со стилями Inspiro Lite.
* Адаптивная вёрстка: мобильный первый, блоки складываются в колонку на экранах <768px.
* Для кнопок: добавить классы `wp-block-button\_\_link` для совместимости со стилями темы.
* Все внешние ссылки: `rel="noopener noreferrer"`, иконки — через inline-SVG или системные шрифты.
* Включить базовую JSON-LD разметку `MobileApplication` (name, description, operatingSystem, applicationCategory, offers).
